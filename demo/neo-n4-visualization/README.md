# Neo N4 架构可视化演示

这是一个使用 Three.js 创建的交互式 3D 可视化项目，用于展示 Neo N4 Layer 2 Rollup 的技术架构、运行原理和执行逻辑。

## 🎯 功能特性

### 核心可视化组件
- **L2 序列器节点**：六边形柱体，青色发光，展示交易收集和批处理
- **Neo 主链 (L1)**：橙色立方体，代表 Neo 主网基础层
- **RollupHub 合约**：绿色八面体，核心合约枢纽
- **zkVM 证明器**：粉色菱形，SP1 零知识证明生成
- **Gateway 网关**：紫色圆环，跨链消息发布

### 动画演示流程
1. **交易收集阶段** - L2 序列器接收用户交易，批量打包
2. **批次封装阶段** - 将交易打包成批次，生成状态根
3. **零知识证明生成** - zkVM (SP1) 生成批次执行的零知识证明
4. **批次提交到 L1** - 将批次承诺和证明提交到 RollupHub
5. **批次终局化** - 验证通过，批次状态终局，更新规范根
6. **Gateway 发布** - 跨链消息根发布到 SharedBridge

### 交互功能
- ▶ **开始演示**：启动完整的 6 阶段动画循环
- ⏸ **暂停/继续**：随时暂停和恢复演示
- 🔄 **重置**：重置到初始状态
- ⚡ **速度切换**：1x/2x 速度切换

### 实时统计
- 批次编号
- 交易数量
- 区块范围
- 状态转换状态
- 证明生成状态

## 🚀 快速开始

### 安装依赖

```bash
cd demo/neo-n4-visualization
npm install
```

### 启动开发服务器

```bash
npm run dev
```

浏览器将自动打开 `http://localhost:3000`

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist/` 目录。

### 预览生产版本

```bash
npm run preview
```

## 📐 架构说明

### 场景布局
```
       L2 序列器                         Neo 主链
      (-15, 5, 0)                      (15, 5, 0)
           ║                                ║
           ╚════════════╗      ╔═══════════╝
                        ║      ║
                    RollupHub (0, 2, 0)
                        ║      ║
           ╔════════════╝      ╚═══════════╗
           ║                                ║
      zkVM 证明器                       Gateway
      (-8, -3, -8)                    (8, -3, 8)
```

### 颜色方案
- 🔵 **青色 (#00ffff)** - L2 序列器
- 🟠 **橙色 (#ff6b00)** - Neo 主链
- 🟢 **绿色 (#00ff88)** - RollupHub 合约
- 🟡 **黄色 (#ffaa00)** - 交易批次
- 🔴 **粉色 (#ff0088)** - zkVM 证明器
- 🟣 **紫色 (#8088ff)** - Gateway 网关

## 🎬 动画细节

### 交易粒子流
- 从场景周围随机位置生成
- 以抛物线轨迹飞向 L2 序列器
- 批量收集时连续生成 20 个粒子

### 批次传输
- 立方体形态，黄色发光
- 旋转动画伴随位移
- 从 L2 → RollupHub → Neo 主链

### 证明光束
- 从 zkProver 到 RollupHub 的闪电效果
- 粉色发光，持续 2 秒
- 表示零知识证明传输

### 组件脉冲
- 各组件在关键阶段产生脉冲效果
- 缩放 1.0x → 1.2x → 1.0x
- 配合对应颜色的发光强化

## 🔧 自定义配置

### 修改动画速度
编辑 `src/scene.js` 中的相位持续时间：

```javascript
const phases = [
    { name: '交易收集阶段', duration: 3000 }, // 毫秒
    // ...
];
```

### 修改组件位置
调整各组件的 `position.set(x, y, z)` 参数。

### 添加新组件
在 `createComponents()` 函数中添加新的 3D 对象并注册到 `components` 对象。
