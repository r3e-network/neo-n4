## 🔄 完整交易生命周期

```
时间轴                     操作                          状态
─────────────────────────────────────────────────────────────────────

T+0s    用户签名交易
        wallet.sendTransaction()                    [已签名]
          │
          ▼
T+0.1s  交易进入 Mempool
        sequencer.addToMempool(tx)                 [待处理]
          │
          ▼
T+2s    Sequencer 排序 & 软确认
        sequencer.orderTransaction(tx)             [软确认] ✓
          │                                         ↑
          │                                      用户看到确认
          ▼
T+300s  Batcher 打包批次 (收集500笔)
        batcher.buildBatch(txs[500])               [打包中]
          │
          ▼
T+310s  执行交易 & 生成状态根
        executor.execute(batch)                    [已执行]
          │
          ▼
T+365s  Prover 生成 ZK 证明
        prover.prove(batch) → proof                [已证明]
          │
          ▼
T+380s  提交到 L1
        rollupHub.submitBatch(batch, proof)        [已提交]
          │
          ▼
T+395s  L1 验证 & 确认
        zkVerifier.verify(proof) ✓                 [L1确认] ✓
          │                                         ↑
          │                                      最终确认
          ▼
T+600s  批次终局 (10分钟)
        状态不可逆                                  [已终局] ✅

─────────────────────────────────────────────────────────────────────
总耗时: ~10分钟 (用户感知: 2秒)
```
