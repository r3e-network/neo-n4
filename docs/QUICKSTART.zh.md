## 🔄 交易流程（从提交到确认）

```
1️⃣  用户提交交易
    │
    ▼
2️⃣  Sequencer 排序（2秒内）
    │ ✓ 软确认，可以显示给用户
    ▼
3️⃣  Batcher 打包批次（5-10分钟）
    │ 收集 500-1000 笔交易
    ▼
4️⃣  Prover 生成 ZK 证明（53秒）
    │ 数学证明状态正确性
    ▼
5️⃣  提交到 L1 RollupHub（15秒）
    │ L1 验证证明
    ▼
6️⃣  最终确认（不可逆）✅
    总时间：~10-15分钟
```

## 💸 如何在 L1 和 L2 之间转移资产

### 存款（L1 → L2）

```bash
# 在 L1 上锁定 100 GAS
SharedBridge.deposit(100 GAS)
    ↓
等待 L1 确认（15秒）
    ↓
L2 自动铸造 100 L2-GAS
    ↓
资产可用（总时间 ~30秒）
```

### 提款（L2 → L1）

```bash
# 在 L2 上发起提款
L2Bridge.withdraw(100 GAS)
    ↓
等待批次最终确认（10-15分钟）
    ↓
在 L1 上提交 Merkle 证明
    ↓
SharedBridge 解锁资产
    ↓
收到 L1 GAS（总时间 ~15-20分钟）
```

**💡 快速提款（2分钟）：** 通过流动性提供商（需 0.1% 手续费）

## 🛠️ 5分钟上手

### 1. 安装工具

```bash
# 克隆仓库
git clone https://github.com/r3e-network/neo-n4.git
cd neo-n4

# 安装依赖
dotnet restore
```

### 2. 启动本地测试网

```bash
# 一键启动（包含 L1 + L2 + 监控）
dotnet run --project tools/Neo.L2.Devnet -- 5

# 等待启动完成（约30秒）
✓ L1 节点启动: http://localhost:10331
✓ L2 节点启动: http://localhost:10332
✓ 监控面板: http://localhost:3000
```

### 3. 发送第一笔交易

```javascript
const { NeoN4Client } = require('@neo-n4/sdk');

const client = new NeoN4Client('http://localhost:10332');

// 发送交易
const tx = await client.sendTransaction({
  from: 'your-private-key',
  to: '0x123...',
  amount: '10',
  asset: 'GAS'
});

console.log(`交易已发送: ${tx.hash}`);
// 输出: 交易已发送: 0xabc123...

// 2秒后软确认
console.log('✓ 软确认');

// 10分钟后最终确认
const receipt = await client.waitForFinality(tx.hash);
console.log('✓ 最终确认');
```

### 4. 部署智能合约


## 🔑 关键技术

### 1️⃣ ZK证明（零知识证明）

**是什么？**
数学证明，证明"状态转换是正确的"，但不泄露具体交易细节。

**为什么重要？**
- ✅ L1 只需验证证明（很快）
- ✅ 不需要重放所有交易（节省Gas）
- ✅ 数学确定性（无需挑战期）

**用什么？**
- **SP1** (Succinct Labs)
- **Groth16** 证明系统
- **53秒** 生成时间（500笔交易）

### 2️⃣ 批次打包（Batching）

**原理：**
```
单笔提交 L1: $5 × 500笔 = $2,500
批次提交 L1: $5 ÷ 500笔 = $0.01/笔

节省: 99.6% 💰
```

**权衡：**
- ✅ 成本降低 500-1000 倍
- ⚠️ 最终确认延迟 10-15 分钟
- ✅ 软确认仍然是 2 秒

### 3️⃣ 数据可用性（DA）

**存储在哪？**
| DA层 | 成本 | 速度 | 去中心化 |
|------|------|------|----------|
| **NeoFS** | 低 | 快 | 高 ✅ |
| **Neo L1** | 高 | 中 | 高 |
| **DAC** | 中 | 很快 | 中 |

**默认：** NeoFS（最佳平衡）

### 4️⃣ 形式化验证

**是什么？**
用数学证明代码的正确性。

**覆盖范围：**
- ✅ 23 个 Z3 模型
- ✅ 91 个测试（100%通过）
- ✅ 配置、批次、结算、桥接、治理

**示例：**
```python
# 证明：相同的批次字段 => 相同的编码
assert encode(batch1) == encode(batch2) → batch1 == batch2
# Z3 结果: UNSAT（证明成立）✓
```

## 💰 经济模型

### 收入来源

```
L2 交易费 = 基础费 + 优先费
           = $0.0001 基础 + $0-0.001 优先
           
日交易量（5,000 TPS）:
  5,000 tx/s × 86,400s = 432M 笔/天
  
日收入:
  432M × $0.0001 = $43,200/天
  
年收入:
  $43,200 × 365 = $15.7M/年 📈
```

### 成本结构

```
月成本:
  • 基础设施: $7,700
  • L1 Gas: $15,000
  • DA 存储: $6,000
  • 运维: $8,000
  ─────────────────
  总计: $36,700/月 = $440k/年

利润:
  $15.7M - $0.44M = $15.3M/年
  
利润率: 97.2% 💎
```

### 盈亏平衡点

```
固定成本: $440k/年 = $1,205/天

盈亏平衡 TPS:
  $1,205 ÷ $0.0001 ÷ 86,400s = 139 TPS

安全边际:
  5,000 TPS ÷ 139 TPS = 36x 🛡️
```
