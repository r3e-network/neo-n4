# Scratch — historical analysis drafts

This directory holds **non-authoritative** analysis, planning and draft reports
produced by earlier tooling/agent sessions. They are retained for reference
only and **do not reflect the current, verified state of the repository**.

Read these as historical artifacts, not as the implementation contract:

- Authority for the system is `doc.md` (see `AGENTS.md`).
- Claims of "certification", "complete" or "100% correct" in these files were
  **not** backed by machine-checked verification at the time they were written
  and must not be cited as evidence of system status.
- For the authoritative verification status, see `scripts/formal/` (result JSONs
  carry `wholeSystemVerified: false`) and `IMPLEMENTATION_STATUS.md`.

If any content here is needed as a live design doc, it should be promoted into
`docs/` and reconciled against `doc.md` first.
